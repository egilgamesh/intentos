# IntentOS 0.1.0 — boot prototype acceptance

Status: **not released**.

This milestone is a developer-only Linux-kernel boot prototype. It is not a newly written kernel and not a graphical operating system.

## Required evidence
- [x] Native PID 1 program compiles statically on x86-64 (local build).\n- [x] Command parser tested locally with help/status/uname.\n- [x] Initramfs archive generated and its contents inspected locally.
- [ ] CI builds kernel + initramfs successfully.
- [ ] QEMU serial log contains `INTENTOS_BOOT_OK`.
- [ ] Interactive commands respond through QEMU serial console.
- [ ] Boot artifacts downloadable from a successful workflow run.
- [ ] Reproducible boot instructions tested on a clean Linux machine.

## Security limitations
No authenticated users, persistent storage, network configuration, verified boot, sandboxing, package signing, or agent permissions. Not suitable for real devices or sensitive data.

## Exit criteria
Mark this milestone complete only after a successful GitHub Actions QEMU boot job and inspection of its logs/artifacts.
