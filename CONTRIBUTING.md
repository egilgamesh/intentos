# Contributing

IntentOS is an early research project. Before implementing a subsystem, open an issue describing the problem, constraints, security boundaries, and acceptance tests.

Prefer small, reviewable changes. Document architectural choices in `docs/adr/`. Add tests for kernel primitives and capability enforcement. Avoid introducing unreviewed unsafe code or privileged AI execution.

The project has not yet selected a license; do not assume contributions or reuse are covered by an open-source license.
